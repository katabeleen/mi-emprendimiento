# Tecnologías del proyecto — Kataa Tejidos

> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Construir la estructura y el diseño visual del sitio web, sin utilizar frameworks ni gestores de contenido. |
| Versionado | Git y GitHub | Guardar, controlar y gestionar las diferentes versiones del código del proyecto. |
| Publicación | GitHub Pages | Publicar el sitio web para que pueda ser visualizado desde internet. |
| Diseño | Whimsical | Crear moodboards, componentes, diagramas y wireframes para planificar la estructura del sitio. |
| Diseño | Google Stitch | Generar y explorar propuestas de diseño e interfaces para el sitio web. |
| Prototipado | Antigravity | Apoyar la creación, edición y desarrollo del prototipo web mediante herramientas de IA. |
| Editor | Claude Code | Apoyar la escritura, modificación y revisión del código durante la construcción del sitio. |

## Qué es funcional y qué es prototipo

| Funcionalidad | Estado en esta versión |
|---|---|
| Navegación del sitio | Funcional |
| Visualización de productos | Funcional |
| Visualización de información de productos | Funcional |
| Formulario de solicitud de cotización | Prototipo visual |
| Proceso de compra | Prototipo visual |
| Pago y despacho | Prototipo visual |

## Integraciones para una versión real

- **Pasarela de pago:** Webpay, Mercado Pago u otra alternativa para recibir pagos en línea.
- **Despacho:** Integración con un sistema de cálculo y seguimiento de envíos.
- **Formulario de contacto y/o cotización:** Conectado a un sistema que permita recibir y gestionar las solicitudes de los clientes.
- **Base de datos:** Para almacenar productos, clientes y pedidos.
- **Instagram:** Para vincular el sitio con las redes sociales.

## Restricciones

- **Plazo:** El proyecto se desarrollará dentro del plazo establecido para la entrega, por lo que se priorizarán las funcionalidades principales del sitio.
- **Marca:** El sitio debe respetar la identidad visual de Kataatejidos, manteniendo el estilo, colores, tipografías y estética.
- **Dispositivos:** El sitio debe adaptarse principalmente a computadores y dispositivos móviles, asegurando una correcta visualización y navegación en ambos.
